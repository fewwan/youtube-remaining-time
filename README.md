# YouTube Remaining Time

## Overview

This Chrome extension enhances your YouTube experience by displaying the remaining time of videos alongside the normal elapsed time. It works by injecting additional time information into the YouTube video player controls.

## Features

- Displays the remaining time of YouTube videos.
- Integrates seamlessly with YouTube's existing time display.
- Automatically updates as the video plays.

## Installation

1. **Download the Extension**: Download the repository.

2. **Open Chrome**: Navigate to `chrome://extensions/`.

3. **Enable Developer Mode**: Toggle the switch in the upper right corner of the page.

4. **Load Unpacked Extension**: Click on the “Load unpacked” button and select the directory where you downloaded the extension files.

5. **Verify Installation**: Ensure the extension appears in your list of installed extensions and is enabled.

## Usage

Once installed, navigate to any YouTube video. The extension will automatically add the remaining time to the video player controls. You’ll see the remaining time displayed next to the normal time.
